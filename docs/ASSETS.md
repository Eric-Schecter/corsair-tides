# Asset credits

- World, boats, creatures, interface, upgrade cards, and effects: original procedural artwork in `scripts/`.
- `assets/creatures/`: animation sheets rendered from that artwork using `--bake-enemies`.
- `web/cover.png`: AI-generated cover created for Corsair Tides.
- Combat and upgrade sounds: synthesized by `scripts/game.gd`.
- `assets/audio/harbor-bgm.wav`: original synthesized composition; generator in `tools/compose_harbor_bgm.py`.
- `assets/audio/sailing-water.wav`: ElevenLabs-generated sailing audio reused from the author's Mistbound project.
- `web/hover.wav`, `web/press.wav` and loading-page structure: reused from the author's Strawboat project.
- Fonts: device system fonts through Godot SystemFont; no system font files are bundled.

No reference-game artwork, recordings, scenes, or source code are bundled.
